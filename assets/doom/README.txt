The game data of FlyDoom (the DOOM of the engine, docs/game/doom.md) goes here: a WAD file.

* freedoom1.wad - Freedoom, the free data. tools/doom/fetch_freedoom.ps1 downloads it here (and COPYING-freedoom.txt, CREDITS-freedoom.txt).
* DOOM.WAD, DOOM2.WAD, doom1.wad ... - the data of the original game. If you own DOOM, FlyDoom finds the Steam copy by itself;
  you can also put the WAD here or name it: FlyDoom.exe --iwad <path>.

The WAD files are not in git and not in the build: every file in this folder except this README is ignored by git.
