# Загрузка и окно загрузки (LD1)

Всё, что идёт дольше доли секунды, показывается пользователю: модальным окном для карт и проектов, индикатором в статус-баре для фоновых задач. Короткие операции ничего не показывают.

## Откуда брались задержки

Замер на `benchmark.json` (1036 сущностей), главный поток, `OpenSceneFromDisk` целиком:

| Конфигурация | Чтение | Разбор JSON | Сущности | Всего |
| --- | --- | --- | --- | --- |
| Debug | 2–14 мс | 330–390 мс | 105–145 мс | 450–530 мс |
| RelWithDebInfo | 1–18 мс | 21–26 мс | 14–31 мс | 40–70 мс |
| `coin_guard_demo`, `rocket_league` (любая) | 0.1 мс | 0.1–1 мс | 0.1–3 мс | 0.5–5 мс |

Скрипты (Python), физика и меши с текстурами в этот интервал не входят: меши и текстуры ResourceManager и раньше читал в фоне (Streaming-задачи с заглушкой), скрипты пересоздаются при следующем кадре Play. Лишних повторных загрузок ресурсов при открытии карты нет: ключи уже в кеше.

Поэтому «долго» складывалось из двух вещей:

1. запуск и открытие большой карты в Debug (`run.bat` по умолчанию) — около полусекунды, в течение которых окно стоит и ничего не рисуется;
2. отсутствие обратной связи: ни окна, ни прогресса.

Разбор JSON в Debug медленный из-за nlohmann без оптимизаций; чтение потоком и чтение строкой дали одно и то же время, поэтому оставлен поток. Сама стоимость не убрана, она переехала с главного потока на рабочий: окно живёт, пока карта читается.

## Как открывается карта

```
UI (главный поток)                       Streaming-воркер
  Begin("Loading map...")  ──────────►   ReadWorldFromFile(loaded)
  кадры рисуются, бар растёт  ◄───────   progress(доля, "Parsing" / "Creating entities" / ...)
  PumpPendingSceneLoad: готово  ◄─────   finished
  CommitLoadedWorld (SwapEntities + SceneLoadedEvent)
  End(), done(true)
```

- `scene::ReadWorldFromFile(loaded, path, logger, progress)` читает, разбирает и строит карту в отдельном пустом `ecs::World`, ничего живого не трогая; `scene::CommitLoadedWorld(world, loaded)` меняет сущности и публикует `SceneLoadedEvent` на главном потоке. `LoadWorldFromJson` — оба шага подряд (поведение прежнее).
- Одновременно грузится одна карта. Выход из редактора ждёт воркер (`WaitPendingSceneLoad` в `Shutdown`).
- Сбой (файл не читается, JSON битый): окно загрузки закрывается, карта остаётся прежней, показывается диалог «Cannot open the map» (`ReportLoadError`).
- Первый запуск: `main.cpp` включает `SetDeferredSceneLoad(true)`; окно с `LoadingState` уже живёт, а карта читается в фоне под сплэшем. `LoadingState` ждёт загрузки карты и стриминга ассетов (вместо прежних 0.5 с «на всякий случай»), но не дольше 20 с.
- Открытие другого проекта (перезапуск процесса): старое окно показывает «Opening project...» 0.7 с, пока новый процесс стартует и ждёт его выхода; в новом процессе — сплэш.

## `editor::LoadingService`

Главный поток или любой другой (внутри мьютекс).

| Вызов | Что делает |
| --- | --- |
| `Begin(label, mode, cancellable, parent)` → `id` | начинает операцию: `Background`, `Modal` или `Splash` |
| `SetProgress(id, 0..1 / <0, detail)` | прогресс только растёт; неопределённый становится определённым, обратно — нет |
| `SetSubtitle`, `SetLabel` | вторая строка и заголовок |
| `End(id)` | конец |
| `Sync(key, active, label, progress, detail)` | для опрашиваемых источников: начинает операцию, пока `active`, и кончает, когда он погас |
| `RequestCancel` / `IsCancelRequested` | отмена (только у `cancellable`) |
| `Visible()` | что показывать сейчас |
| `HasModal()`, `HasSplash()` | редактор не принимает ввод / рисуется только сплэш |

Правила времени (спека `.team/design/ld1-spec.md` §0): показывать после 200 мс; если показали — держать не меньше 500 мс; вложенная операция (`parent`) показывается через внешнюю: заголовок внешней, деталь самой внутренней. Пока операция не дошла до порога, но модальная, ввод в редактор уже заблокирован (невидимое модальное окно).

## Что подключено

| Операция | Форма | Где |
| --- | --- | --- |
| Open Map, Open из Content Browser, New Map | модальная «Loading map...» | `Application::BeginOpenScene` |
| Revert Map | модальная «Reverting map...» | `Application::BeginRevertScene` |
| Старт редактора | сплэш на весь экран | `Application::Initialize` + `SceneEditor::DrawStartupSplash` |
| Open Project, New Project | модальная «Opening project...» → сплэш нового процесса | `Application::RestartWithProject` |
| Миниатюры (`ThumbnailService`) | фон, «Generating thumbnails, N left» | `Application::SyncBackgroundOperations` |
| Ассеты, которые ещё стримятся | фон, «Loading assets, N left» | там же |
| Reload Scripts / F5 | фон, «Reloading scripts» | там же (`ScriptSystem::IsReloadPending`) |
| Просмотрщики (текстура, меш) | спиннер на полотне через 200 мс | `SceneEditorViewers.cpp` |

В статус-баре перед индикатором режима — кнопка задач (спиннер, имя самой старой, чип «N tasks», мини-бар); клик открывает список «BACKGROUND TASKS».

## Проверка

- `ctest`: `loading_service` — порог показа, минимальное время, прогресс не идёт назад, отмена, `Sync`, вложенность, потоки.
- Вручную в редакторе: `benchmark.json` открывается из Content Browser с окном «Loading map...» и растущим баром, окно не «Не отвечает»; маленькие карты — без окна; битая карта — диалог; пустой кеш миниатюр — кнопка задач в статус-баре; запуск с `--scene` — сплэш.
- Ручная проверка медленных операций: `MYENGINE_LOADING_DEBUG_DELAY=<мс>` (по умолчанию выключено) растягивает каждый шаг — одна миниатюра за столько миллисекунд, фоновая загрузка меша или текстуры ждёт столько перед чтением, — чтобы попап «BACKGROUND TASKS» и спиннер просмотрщика можно было увидеть глазами.
