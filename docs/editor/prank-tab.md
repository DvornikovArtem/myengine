# Пасхалка «🔞 ПОРНО» в редакторе (PR1)

Шутка по мему «папка с порно на рабочем столе». В редакторе рядом с Viewport стоит максимально заметная вкладка **ПОРНО**: пульсирует розовым, у неё бейдж «3», справа в главном меню моргает кнопка. Внутри — Проводник Windows, в нём десять папок одна в другой (с каждой глубже краснее, крупнее предупреждения, окно трясёт), между папками — гэги (капча, пейвол, «вы точно не Иван?», возрастной контроль, видео на 99 %, UAC), а в самой глубокой лежит **«AI-генератор 18+»**. Это настоящий ассистент редактора в другой одежде: что бы ни спросили, он собирает в открытой сцене маленькую безобидную игру по каламбуру на запрос.

Вся шутка — в разрыве между обёрткой и содержимым. **Настоящего 18+ нигде нет:** ни картинок, ни текста, ни имён объектов. Слова «порно», «хентай», «фури», «голые» встречаются только в названиях папок, кнопок и репликах-обёртках; внутри — игры, полигоны, курсовая и Иван. Тест `prank` следит, что в сценах и скриптах этих слов нет.

## Как включить, как спрятать

- **По умолчанию включено.** Вкладка стоит в узле Viewport, справа от него, и при запуске редактора она активна (первое, что видно).
- `Window ▸ Пасхалка «ПОРНО»` — галочка, она же `"prankTab": true|false` в `%APPDATA%\myengine\editor_settings.json` (остальные ключи файла при записи сохраняются). Снятие прячет вкладку сразу, возврат показывает сразу.
- `myengine.exe --no-prank` (то же `MYENGINE_NO_PRANK=1`) — спрятать на один запуск, **вместе с пунктом меню**: на защите лабы её не должно быть видно ни в каком виде.
- Спрятанная пасхалка — это ни окна, ни кнопки в меню, ни бейджа, ни записи окна в `imgui.ini` (запись, прочитанная из файла, сбрасывается: `ImGui::ClearWindowSettings`), ни лишних шрифтов в атласе. В игре для игроков (`MYENGINE_SHIPPING`) её нет вовсе.

## Как это устроено

Файлы в `engine/src/ui/editor/`:

| Файл | Что в нём |
| --- | --- |
| `PrankStrings.h` | **все** тексты и таблицы: уровни (папки, файлы, баннеры, тряска, «Свободно»), палитры, реплики гэгов, генератор, слова для выбора сцены, ответы. Шутки правятся здесь, без поиска по коду |
| `PrankTab.{h,cpp}` | окно с вкладкой (пульс `#FF2D7A ↔ #FF5A3C` раз в 1,2 с, свечение, знак «18+» и бейдж «3» поверх вкладки; бейдж гаснет, когда вкладка была передней 2 с подряд), кнопка в главном меню (моргает раз в секунду), переключение «Проводник ↔ генератор» |
| `PrankExplorer.{h,cpp}` | Проводник: раскладка Windows 11, значки папок и файлов (рисуются draw list'ом), хлебные крошки, навигация (мышь, `←`/Backspace/Alt+←/боковая кнопка, двойной щелчок, Enter), тосты, меню «Создать/Сортировать/Просмотр», «Блокнот» и просмотрщики файлов (диск, синусоиды, куб, чайник), палитры 10 уровней, тряска, наклон |
| `PrankGags.{h,cpp}` | капча «голые полигоны», пейвол 299 ₽, «Вы точно не Иван?», возрастной контроль (кнопка «Мне нет 18» убегает), «видео» на 99 % и ошибка видеопамяти, UAC |
| `PrankGenerator.{h,cpp}` | экран генератора: шапка, фейковая история, чат, прогресс «Генерирую… N %», плашка цензуры над превью, кнопки «Смотреть / Не сейчас / ▶ Играть», запасной режим |
| `PrankMatcher.{h,cpp}` | запасной режим без нейронки: слова → одна из пяти мини-сцен; ответы и шаги. Без ImGui, под тестом |
| `PrankSettings.{h,cpp}` | `prankTab`, `--no-prank`, состояние процесса. Без ImGui, под тестом |
| `PrankUi.{h,cpp}` | цвета, текст в запечённых размерах, свечение, кнопки, список кнопок кадра для скриптового ввода |
| `SceneEditorPrank.cpp` | связка с редактором: создание вкладки, сервисы для генератора (снимки сцены и Undo, Play, второй ассистент), команды `editor prank ...` |

Шрифты. Атлас строится один раз при старте, поэтому для пасхалки при старте (если она включена) запекаются одиннадцать размеров Inter SemiBold (12…56 px) с набором символов шире обычного (рубль, стрелки, минус, бесконечность). Цветных эмодзи нет: символы, которых шрифт не умеет, не рисуются (`Clean` в `PrankUi.cpp`), а 🔞 везде заменён нарисованным знаком «18+». Тофу-квадратов нигде нет.

### Проводник

Десять уровней из `PrankStrings.h` (`kLevels`), цвета — из таблицы `kPalettes`; при смене уровня палитра перетекает за 250 мс. Первые семь уровней — как в макете. **Три последних (8–10) чуть темнее макета** (`#D6335E`, `#BE1E48`, `#A30D2E` вместо `#FF6688`, `#EC2149`, `#D10F37`): белый текст на макете имеет контраст 3,4 / 4,3 / 5,5 при правиле 4,5; выделение и наведение там тоже тёмные. Тест `prank` проверяет контраст текста на фоне, на боковой колонке, панелях, выделении и наведении на всех десяти уровнях. Текст на полях (адресная строка, поиск) переключается на тёмный, когда поле светлое, а текст белый.

Тряска: при входе на уровень затухающая 600 мс (`A·3·(1−t)` по x и `A·1,5·(1−t)` по y), в покое — толчок на 150 мс раз в 4 ± 1 с; наклон на уровнях 8–10 (−0,4°, +0,8°, −1,2°) — поворот вершин draw list'а вокруг центра. Значки папок с седьмого уровня «дышат» (1 ↔ 1,04). Клики при наклоне попадают в нужное место с допуском в несколько пикселей (наклон ≤ 1,2°).

Гэги проходятся один раз за запуск (потом тост «Вы уже доказали»). Esc в гэге возвращает на уровень, с которого шли (в «видео» Esc не работает — оно само заканчивается).

**Возрастной контроль без Face ID.** Спека предусматривает вариант через Face ID (камера, «Артём, вам 3 курс… ладно, проходи»); этот вариант в PR1 **не сделан** (`AgeCheckFace` в `PrankGags.h` — готовая точка, но редактор пока даёт пустой): камера в пасхалке не включается никогда, работает вариант с кнопками «Мне есть 18» / убегающая «Мне нет 18».

### Генератор

Экран занимает всю вкладку; `←` в шапке возвращает в Проводник (на уровень 10). Фейковая история слева (клик — тост «Этот чат удалён»); «Новый запрос» очищает чат. Фейковые проценты в прогрессе привязаны к событиям: 3 % на старте, потом ряд 12, 37, 37, 37, 69, 88, 99 — по одному шагу на каждый вызов инструмента (в запасном режиме по таймеру, 3 с всего).

**С ассистентом** (`assistant.backend` = `claude` или `codex` в `editor_settings.json`): `SceneEditor` создаёт **второй `AssistantPanel`** (его не рисуют, он нужен ради сервиса и моста) со своим `AssistantService`, чатом, пайпом моста (`\\.\pipe\myengine-assistant-prank-<pid>`; два моста не могут делить имя процесса) и промптом `assets/assistant/prank_prompt.md`, который дописывается после обычного системного промпта (`AssistantPanelConfig::extraPromptFile`; собранный файл лежит в `Saved/assistant/`). Обычная панель Assistant не изменилась: правки в `AssistantPanel.*` — два необязательных поля конфигурации и их применение в `StartBackend`; ни одна функция рисования не тронута. Настоящие чаты этого режима в фейковый список не добавляются.

Как идёт запрос: текст уходит в `AssistantService::Send`; пока модель работает, шаги инструментов показываются под полосой; когда ассистенту нужна карточка Apply (любой изменяющий вызов), пузырь переходит в состояние «готово»: превью закрыто плашкой «Только для взрослых», внизу «Смотреть» (это Apply: карточки подтверждаются, пока ход идёт) и «Не сейчас» (Reject и отмена хода). Если в сцене есть несохранённые изменения, перед «Смотреть» спрашивается «Сохранить текущую сцену?» (сохранить и смотреть / смотреть без сохранения / отмена). После применения плашка тает за 300 мс, появляется «▶ Играть» (вкладка Viewport и Play). Если ассистент не ответил (нет сети, CLI упал) — запрос тихо уходит в запасной режим. Правила обычного ассистента (только `assets/scripts`, `assets/prefabs` и инструменты движка) остаются; промпт требует безобидных названий и отказа на запросы про детей, реальных людей и насилие над живыми.

Превью — **нарисованная** draw list'ом картинка игры (осьминог, лисичка, лава, шипы, колёса), одна на сцену; для ответов ассистента берётся картинка по ключевому слову запроса. Снимок рендера Viewport для превью в PR1 не используется.

**Запасной режим** (ассистент выключен — `none` — или CLI не найден): та же страница, в шапке «модель: локальная (без интернета)». Запрос ищется по словам (`PrankMatcher.cpp`, регистр и «ё» не важны):

| Слова | Мини-сцена | Файл |
| --- | --- | --- |
| щупальц, осьмин, хентай | босс-осьминог, щупальца — `chaser`ы, монетки — счёт | `assets/prank/scenes/octopus.json` |
| фури, лис | лисичка собирает монетки | `fox.json` |
| горяч, лава, огонь | пол — лава, падают огненные шары (`prank_fireballs.py`) | `lava.json` |
| жёстк, хард | одно касание и всё (`prank_hardcore.py`) | `hardcore.json` |
| голы | колёса без кузова играют в футбол (`prank_football.py`) | `nakedcars.json` |
| дети, реальные люди, насилие | шутка-отказ и случайная сцена | — |
| иначе | случайная из пяти | — |

Мини-сцены собраны из того, что уже есть в проекте (демо «монеты под охраной»: `game_manager.py`, `coin_spawner.py`, `enemy_spawner.py`, префабы `coin`, `chaser`, `firework`, модели `crate`, `sphere`, `pyramid`, `rl_wheel`), плюс четыре маленьких скрипта `prank_*.py` (заголовок на HUD, огненные шары, «одно касание», футбол). Новых тяжёлых ассетов нет. «Смотреть» загружает сцену как снимок (`RestoreSceneSnapshot`) **одним шагом Undo** (`Ctrl+Z` возвращает сцену пользователя); если шла игра, сначала останавливает её.

## Проверка

- `ctest -R prank` — подбор сцены по словам (19 запросов с чипами, отказы, случайный выбор с зерном), переключатель (`prankTab`, `--no-prank`, сохранение с остальными ключами файла, галочка меню), таблицы (цепочка папок, рост тряски и баннера, контраст палитр), пять сцен (JSON, камера/игрок/менеджер, скрипты на месте, ни одного «взрослого» слова в сценах, скриптах; правило в промпте).
- `myengine_prank_smoke <octopus|fox|lava|hardcore|nakedcars>` — ручной тест (окно DX12, как `myengine_gameplay_smoke`): играет сцену 8 с и проверяет, что нет ошибок скриптов и появились монеты, щупальца, огненные шары, а мяч после гола возвращается в центр.
- Скриптовый ввод для снимков: `MYENGINE_UI_SCRIPT` и команды `editor prank ...`: `level N`, `item N`, `close`, `gag captcha|paywall|ivan|age|load|video|uac`, `generator`, `ask <текст>`, `watch`, `play`, `stop`, `focus`; ввод — `click x y` / `click @<id>` (кнопка вкладки по id, например `@pcapok`, `@ptile0`, `@pgwatch0`) и `dclick`, `move x y`, `esc`, `enter`, `type <текст>`. Мышь и клавиши подаются по одному событию за кадр, так что ImGui видит каждое нажатие; команды работают и при выключенной пасхалке (меню, `--no-prank`).
- Кадры всех уровней, гэгов, генератора (с ассистентом и без), переключателей — в `.team/tasks/pr1-evidence/`.

## Что не сделано, и ограничения

- Face ID в возрастном контроле (см. выше), цветные эмодзи (шрифта `seguiemj` нет в атласе), снимок Viewport для превью, настоящий blur под плашкой цензуры (плашка непрозрачна на 86 %).
- Чаты второго ассистента лежат в общей папке сессий Claude Code проекта, поэтому в списке чатов обычной панели Assistant могут появиться запросы из генератора.
- `Application` сохраняет открытую сцену при выходе из редактора: мини-сцена, применённая «Смотреть», как и любая правка, попадёт в файл сцены, если её не откатить (`Ctrl+Z`) и не закрыть без сохранения.
