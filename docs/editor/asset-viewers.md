# Просмотрщики ассетов (AV)

Двойной клик по ассету в Content Browser открывает его вкладкой рядом с Viewport — как asset editors в Unreal. Просмотрщики только читают файлы; единственное, что можно править, — свойства материала (Shader, Texture, Tint), и они идут через те же команды отмены, что в Material Editor.

## Как открыть

| Откуда | Что открывается |
| --- | --- |
| Двойной клик или «Open» в контекстном меню Content Browser | меш, текстура, материал, префаб |
| Кнопка `external-link` в строках Mesh и Texture панели Details | меш или текстура строки |
| Кнопка `external-link` на превью Material Editor | материал |
| Кнопка `external-link` справа от комбо в Prefabs | префаб |
| Кнопка «Show in Material Editor» в просмотрщике материала | Material Editor показывает этот материал |

Повторное открытие того же ассета переносит фокус на уже открытую вкладку. Вкладка называется по имени файла (с расширением у текстуры и меша, без — у материала и префаба); её ID — `###viewer:<тип>:<путь>`, поэтому сохранённая раскладка не путается. Пока просмотрщиков нет, у Viewport нет полосы вкладок; она появляется с первым просмотрщиком и исчезает с последним.

## Раскладка

Слева полотно на всю высоту, справа панель 344 px (Info, Details или Entities), между ними разделитель 2 px. Кнопки полотна собраны в группы на плашке `#151515@0.86`, активная кнопка — `kPrimary`; внизу слева подсказка по управлению. Мышь работает только над полотном: камера сцены не реагирует.

### Texture

- Fit (`F`), 1:1 (`1`), текущий зум; колесо — зум к курсору (×1.25, от 1% до 40000%), перетаскивание — пан.
- R, G, B, A — переключатели каналов; если включён только A, альфа показывается серым. Шахматка под прозрачностью включается кнопкой `grid-3x3`.
- Nearest | Linear. По умолчанию Nearest для текстур меньше 64 px. На большом увеличении Nearest рисует пиксели квадратами, поэтому края чёткие; иначе картинка выводится обычным фильтром.
- Если включены не все каналы, строится копия текстуры с маской (`ThumbnailService::CreateViewTexture`), и пересоздаётся только при смене каналов или перезагрузке файла.
- Info: Size, Channels, sRGB, Alpha (есть ли пиксели с альфой меньше 255), Source format; File: File size, Modified, Path, Show in Explorer, Copy Path.

### Mesh

- 3D-вид на цели `ThumbnailService`: градиентный фон, сетка пола (шаг 1 м, 10 м и 100 м для больших мешей), меш стоит на полу. Lit | Wireframe, сетка, bounds (пунктир `#F0C674`).
- ЛКМ — орбита, ПКМ/СКМ — пан, колесо — зум, `F` или кнопка справа — кадрировать.
- Info: Vertices, Triangles, Bounds «X × Y × Z»; Preview: материал превью (по умолчанию предложенный, `ResolveSuggestedMaterialForMesh`; выбор меняет только превью и не трогает файлы); File.

### Material

- Большое живое превью (тот же `DrawMaterialPreviewView`, что в Material Editor): Sphere | Cube, Lit | Wireframe, орбита ЛКМ, колесо — зум.
- Панель Details: категория Material (Shader, Texture, Tint — тот же код `DrawMaterialCategory`, что в Material Editor) и строка «Edits apply live to every entity using this material.». Правки видны сразу во всех открытых копиях, отменяются Ctrl+Z.

### Prefab

- Все меши шаблона на полу, с сеткой и общими bounds, оверлей как у Mesh.
- Панель Entities: шапка с чипом Read-only, дерево сущностей (с иерархией), под ним сводка выбранной: Mesh, Material, Rigidbody, Collider, Script. Выбранная сущность подсвечивается на полотне синей рамкой.
- «Edit Props in Prefabs Panel» открывает Prefabs с этим шаблоном: `props` правятся только там.
- Файл читается заново, когда меняется на диске; камера остаётся.

### Файл не открылся

Вместо полотна — «Cannot open this file», путь и подсказка про Output Log; в панели только категория File. Причина загрузки записана в лог. Определяется через `ResourceManager::LoadFailed(path)`: загрузчик отвечает запасным ассетом, и просмотрщик иначе не отличил бы его от настоящего.

## Что изменилось в API

- `ThumbnailService::ReadPrefab(path, entities)` — сущности префаба: имя, родитель, меш и материал, мировая матрица, сводка Rigidbody / Collider / Script.
- `ThumbnailService::CreateViewTexture` / `DestroyViewTexture` — текстуры, которые просмотрщик строит сам (между кадрами).
- `LiveViewRequest::wireframe` — вид рисуется каркасом (состояние адаптера восстанавливается после прохода).
- `ResourceManager::LoadFailed(path)`.
- Просмотрщики регистрируются в `ContentBrowserHooks::onOpenAsset` (`SceneEditorAssets.cpp`): текстура, меш, материал и префаб открываются вкладкой; прежние действия `openPrefab` / `openMaterial` остались запасными.
- Правка Tint и других свойств материала перетаскиванием даёт одну запись в истории на весь жест (`SceneEditor::CommitMaterialWidgetEdit`): раньше при перетаскивании записи не было.
