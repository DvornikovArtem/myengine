# ЛР3. Замеры «до» (рефлексия шейдеров, вариант Б)

Baseline, снятый на `main` `a2d0670` до первой правки ЛР3. После задач A1-A4 те же прогоны повторяются в `docs/measurements/lab3/after/`, цифры сравниваются по таблицам ниже. Код движка при замерах не менялся.

## Условия

| Параметр | Значение |
|---|---|
| **Коммит** | `a2d0670` (`main`, до ЛР3; поверх него позже вошёл только документ `docs/render/architecture.md`) |
| **Конфигурация** | RelWithDebInfo (`TRACY_ENABLE` только в ней) |
| **Машина** | AMD Ryzen 7 170 (16 логических ядер), 15 ГБ ОЗУ, NVIDIA GeForce RTX 3050 Laptop GPU (драйвер 32.0.15.9576), Windows 11 |
| **Tracy** | клиент 0.14.1 (сабмодуль), `tracy-capture -f -s 25` / `tracy-csvexport -u` из `Documents\apps\tracy` |
| **RenderDoc** | 1.46 (`renderdoccmd convert -c xml` для отчёта) |
| **VSync** | выключен (`MYENGINE_VSYNC` не задана) |
| **Окно** | 1280x720, редактор: вьюпорт сцены 856x345, остальное занято панелями |
| **Режим** | `--play`, ввод не трогался, камера сцены не двигалась |
| **Сцены** | `benchmark.json` (1036 сущностей, 1025 с `Rigidbody`, 999 draws); `rocket_league.json` в **меню** (нажатия 1-4 не было: арена, 67 сущностей, 79 draws) |
| **Прогонов** | 3 на сцену на каждый вид замера (Tracy, `--frame-stats`); RenderDoc: по одному захвату |

Перцентили считаются линейной интерполяцией по всем вызовам зоны в окне (`analyze_tracy.py`). Колонка «Вызовов в окне» у `Dx12RenderAdapter::Draw` показывает число вызовов `Draw` (в бенчмарке около 1000 на кадр).

## Что важно знать про сцены

- `rocket_league` в меню - очень лёгкая сцена: кадр около 1.8 мс (около 470 FPS без VSync), GPU 0.08 мс. Она годится для проверки, что визуал и число draws/PSO не изменились, но не для оценки цены на CPU. Цену ЛР3 мерить по `benchmark`.
- В `benchmark` вьюпорт рисует ещё и debug-линии коллайдеров (1 draw, около 30 тыс. линий): это отдельный проход `Debug Lines` с собственной root signature.
- Время GPU `--frame-stats` берётся из timestamp-запросов (QA1), оно меряет проходы внутри кадра без ожидания Present.

Выводы «до» (для сравнения после A2):
- `benchmark`: кадр 19.7-24.8 мс (медианы трёх прогонов), `RenderFrame` 8.2-9.2 мс, из них `RenderSystem::Render` 5.3-6.0 мс (`BuildDrawItems` около половины), `DebugRenderSystem::Render` около 2.3 мс, `EndFrame` + `Present` около 1 мс. Сам `Dx12RenderAdapter::Draw` стоит около 0.3-0.5 мкс на вызов, около 0.4 мс на кадр: накладные расходы адаптера малы, поэтому цена рефлексии на draw заметна, только если появится поиск имён по строке.
- Прогоны `benchmark` расходятся (медианы кадра 23.0 / 19.7 / 24.8 мс): при N=3 разброс около 25%, различия «до/после» меньше этого порога нужно подтверждать повторными прогонами.
- `rocket_league` (меню): кадр 1.8 мс, `RenderFrame` 1.0 мс; прогоны совпадают в пределах 3%.

## Чего в «до» нет

- Цены создания PSO/root signature на старте и рефлексии: Tracy-зон для них ещё нет (`Shader::Compile`, `Shader::Reflect`, `Shader::BuildPipeline` появятся в A1/A2), код не трогали. В «после» это будет разовая абсолютная цифра.
- Загрузки ресурсов (кэш тёплый), загрузки сцены, hot reload шейдеров.

## Структура папки

- `README.md` - этот файл; `results_tracy.md/.json` - таблицы Tracy (результат `analyze_tracy.py`);
- `traces/*.tracy` - 6 трейсов (3 на сцену, по 25 с, 5-7 МБ); `traces/csv/*_Frame.csv`, `*_RenderFrame.csv` - выгрузка зон `Frame` и `RenderFrame` (`tracy-csvexport -u`, фильтр по точному имени, как в ЛР1);
- `<сцена>_run<N>.stats.md/.json` - `--frame-stats 900`;
- `frame_report_*.md/.json`, `frame_*.jpg` - RenderDoc;
- `run_tracy.ps1`, `run_before.ps1`, `analyze_tracy.py` - как повторить (из корня репозитория, после сборки RelWithDebInfo).

## Как повторить для «после»

```
powershell -File docs\measurements\lab3\before\run_tracy.ps1        # 6 трейсов
python docs\measurements\lab3\before\analyze_tracy.py               # results_tracy.md/json + csv
powershell -File docs\measurements\lab3\before\run_before.ps1       # --frame-stats 900
```

Для «после» скопировать скрипты в `after/`, условия оставить теми же (сцены, окно 5-20 с, N=3, VSync выкл., RelWithDebInfo).
