FlyDoom: third-party software and data
======================================

FlyDoom is the classic DOOM running on the educational engine myengine (ITMO, a course on game engine architecture). This file lists what is in this
package that is not ours, under which license, and where to read the license. The full text of a license that is not repeated here is in the
folder licenses. The source code of FlyDoom: SOURCE.txt.

3. The fly brain (the file assets\flybrain\malecns_v1.fbrain, when it is in the package)
--------------------------------------------------------------------------------

The wiring diagram of the brain of a male fruit fly: the MaleCNS v1.0 connectome (Janelia FlyEM, University of Cambridge, MRC LMB, Google Research).
  Berg S. et al. (2026) Sexual dimorphism in the complete Drosophila male central nervous system connectome.
  Cell 189(18):5504-5526.e15, doi:10.1016/j.cell.2026.08.015
  Release: https://male-cns.janelia.org/download/ ; the copy that was read: the mirror https://huggingface.co/QuixiAI/MaleCNS (Hartford E. 2026, doi:10.57967/hf/10410)
License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
Changed by us: the traced neurons and their connections were taken from the release and written to a compact binary file (.fbrain); the weight of a
connection is the number of synaptic contacts times the sign of the neurotransmitter of the sending neuron; the annotations are reduced to type, class,
side, transmitter, position and the column of the optic lobe. The same notice is inside the file (the section ATTRIB). The file assets\flybrain\swarm_circuit.fbrain (the enemy flies of the mode Swarm) is a small piece of it (1,660 neurons on the paths of looming to the descending
neurons), cut out by us with the same attribution inside the file. The signs follow DOOMFLY
(https://github.com/nftechie/doomfly, MIT license, Alex Wormuth).
