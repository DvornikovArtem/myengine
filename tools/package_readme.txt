ROCKET ARENA  {VERSION}
=======================

Машинки, мяч и ворота: матч в духе Rocket League на учебном движке myengine
(ИТМО, курс по архитектуре игровых движков).

КАК ЗАПУСТИТЬ
-------------
1. Распакуйте архив целиком в любую папку (не запускайте RocketArena.exe прямо из zip).
2. Запустите RocketArena.exe. Нужны Windows 10 или 11 (64 бит) и видеокарта с DirectX 12.
   Ничего ставить не нужно: библиотеки Visual C++ и Python лежат рядом с игрой.
3. Первый запуск чуть дольше: игра один раз строит кэш моделей и текстур.

Игра ничего не пишет в свою папку. Логи, настройки и кэш лежат в
%LOCALAPPDATA%\RocketArena (откройте через Win+R). Чтобы начать с нуля, удалите эту папку.
Если игра не запускается, пришлите файл %LOCALAPPDATA%\RocketArena\logs\myengine.log.

УПРАВЛЕНИЕ
----------
Клавиатура и мышь                                    Геймпад Xbox
  W / S         газ и тормоз (в воздухе: тангаж)       правый / левый триггер
  A / D         руль (в воздухе: рысканье)             левый стик по горизонтали
  Q / E         крен в воздухе                         LB / RB
  ЛКМ           буст                                   B
  ПКМ           прыжок (второй раз с направлением:     A
                додж)
  Пробел        камера «на мяч» / свободная            Y
  Shift         дрифт (powerslide)                     X
  Tab           таблица счёта                          Back
  M             меню                                   Start
  Esc           выйти из режима игры

Клавиши можно переназначить: файл assets/data/rl_controls.json (кнопки и оси, формат внутри);
личные настройки можно положить в %APPDATA%\myengine\rl_controls.json.

СЕТЬ И STEAM
------------
Матч по сети: один игрок запускает хост (--rl-host), остальные подключаются (--rl-join адрес).
Подробности и параметры командной строки - docs/game/rl-online.md в репозитории проекта.
Если рядом с RocketArena.exe лежат steam_api64.dll и steam_appid.txt, сборка собрана с
поддержкой Steam; иначе игра работает офлайн и по UDP.

ЛИЦЕНЗИИ
--------
Игра использует стороннее программное обеспечение. Тексты лицензий лежат в папке licenses
(начните с THIRD_PARTY_NOTICES.txt). Модели, текстуры и звуки игры сгенерированы
процедурно скриптами из репозитория; чужих сэмплов и моделей в них нет.
